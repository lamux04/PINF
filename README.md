# University Schedule Generator

This project is a web application that generates university schedules automatically.

The system stores information about:
- teachers
- classrooms
- degrees
- subjects
- theoretical hours
- practice hours

Based on these constraints, the application generates valid schedules.

## Technologies
- JavaScript / Node.js
- PostgreSQL
- REST API

## Features
- Manage teachers and subjects
- Store academic information in PostgreSQL
- Generate valid schedules automatically
